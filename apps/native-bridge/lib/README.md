# GridDB native runtime libraries

Place your compatible runtime JARs here:

- `gridstore.jar`
- `gridstore-arrow.jar`
- `arrow-memory-netty.jar`
- `gridstore-advanced.jar` (licensed GridDB Cloud library, obtained from your portal)

`npm run setup:mac` installs the public dependencies. Download the Cloud library separately. JARs are ignored by Git and are not bundled with this draft.
